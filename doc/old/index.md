# Historical documentation entry point

> **Historical — superseded.** Start with the [Sandbar README](../../README.md), [quick start](../guides/quickstart.md), or [documentation archive index](README.md).

This was the entry point for the early REST-oriented documentation. It introduced a Datomic metamodel of classes, properties, typed entities, and inherited slots, with Pedestal providing HTTP access and Component managing application lifecycle. Its main route was installation → architecture → metamodel → endpoint reference.

The current documentation separates concepts, task guides, and mechanical references. The earlier material is accounted for in the [archive index](README.md); the old build commands and endpoint shortcuts have been retired from this landing page to avoid presenting a second setup guide.
