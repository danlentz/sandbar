definition: A reference memorial — provides structured indexing of authoritative sources on a topic (specs, papers, repos, tutorials), with typed-edge crosslinks via `cites:` / `documents:` / `evidences:`.  Companion to `library` memorials (libraries describe the WHAT of a piece of software; references describe the WHERE its documentation lives).
scope-note: Use for memorials ABOUT the reference-memorial concept.  NOT for individual references — those memorials carry `memory-type :reference` in their frontmatter.
