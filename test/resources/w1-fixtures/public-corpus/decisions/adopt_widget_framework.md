A public-corpus decision memorial used by the W1.J release-gate fixture.

## Context

The public project needed a shared UI layer. Several candidate
frameworks were evaluated against the team's clarity preferences.

## Decision

Adopt the widget framework for all public-facing UI work, and cite
the clarity interaction rule as the governing principle.
